# Oscars Salon | English + Tiếng Việt

Premium, responsive salon website using the supplied stylized storefront artwork as a **still image**, not an animated video. This is a fully editable React / TypeScript / Vite project with separate English and Vietnamese pages.

## Pages

- `/` — English homepage (all content in English)
- `/vi/` — Trang chủ tiếng Việt (all website content translated into Vietnamese)

Each page has its own HTML entry point, metadata and `lang` attribute. The navbar has an **EN | VI** switch visible on both desktop and mobile. The sections are localized separately: hero, about, services, location, business hours, navigation, and footer. The salon name, legal address, phone number, and Google links remain unchanged.

## Run in VS Code

```bash
npm install
npm run dev
```

Visit `http://localhost:5173/` for English or `http://localhost:5173/vi/` for Vietnamese. The language switch switches between the two URLs.

## Build for hosting

```bash
npm run build
```

Deploy the resulting `dist/` folder to Cloudflare Pages. Because this project has separate HTML entry points, the Vietnamese page is available at `/vi/` without needing a single-page-app fallback.

For a simpler alternative without using Node or npm, use the separately supplied **Cloudflare-ready deployment ZIP**. It includes the fully rendered HTML in both languages, the image, stylesheet and a tiny script for the mobile menu and opening-hours indicator.

### Cloudflare Pages (Git integration)

- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

### Cloudflare Pages (Direct Upload)

Upload `oscars-salon-cloudflare-still-bilingual.zip`, or the unpacked files, as the new deployment.

## Images

- `public/oscars-storefront.webp` — **static** image shown in the homepage hero (both languages)
- `public/oscars-storefront-full.png` — larger still image in the storefront section
- `public/favicon.svg` — site favicon

There are **no MP4, WebM, GIF or video elements** in this version. The storefront is a stylized illustration rather than a verified photograph of the business premises.
